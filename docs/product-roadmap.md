# Tempo roadmap

## Current position

**Phase 1 — release verification in progress (2026-09-14).**

The creator design foundation and scoped performance-history implementation passed local and hosted CI. The database migration is installed and signed-in preview verification is underway. Finish application release and production verification before marking this phase complete. Verification evidence and limitations are recorded in `creator-design-foundation.md`.

## Agreed sequence

1. **Finish the current release:** verify and release brand-scoped creator history and shared metrics.
2. **Bring the approved design into Tempo:** apply approved roster and creator-profile layouts, preserving existing workflows.
3. **Extend consistency across the app:** navigation, dashboard, reporting, forms, tables, loading and empty states.
4. **Review features page by page:** agree what to add, simplify, change, or remove based on manager and brand-owner needs.
5. **Deepen creator intelligence:** historical agreements, renewal comparisons, top videos, posting reliability, authorized cross-brand analysis.
6. **Expand finance operations:** flexible deals, payroll preparation, payment approval handoffs, collections, and budgets.
7. **Prepare broader rollout:** onboarding, tenant isolation, load testing, monitoring, recovery, and pilot brands.

TikTok API work runs alongside these phases: confirm scopes and data, build imports, reconcile against CSVs, then replace manual uploads. Stripe billing remains deferred.

## Working agreement

- Briefly state the current phase in batch updates and completion summaries, especially when the conversation changes direction.
- Update this file when a phase changes, including release evidence and the next phase. Do not mark a phase complete while required verification remains.
- Keep the larger goal visible: make creator management operations effortless to scale so brands and agencies can grow TikTok Shop revenue.
- Preserve the approved visual direction and shared design rules in `creator-design-foundation.md`; the workspace archive at `context/tempo-design-system` holds the approved references.
- Implement, preview, verify, release, then check production. Revisit user design approval when the direction or workflow materially changes.
